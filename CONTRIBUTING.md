# Contributing

This is a template, not an app.

- Found a bug? Open an issue.
- Got an improvement? PR welcome.
- Keep changes generic. This starter serves many members, not any one client. If a change only makes sense for one specific site, it belongs in that site's fork, not here.

Stick to the design rules in the README (no rounded corners past 2px, no gradients, no em dashes in copy). Keep the dependency list small. If a new package is needed, explain why in the PR description.
