FAQ

Things people ask

Do I own the code and content? +
Yes. Everything sits in a git repo in your GitHub account, the domain is in your name, and hosting is set up on your account. If we ever part ways, the whole site comes with you.
How do edits work? +
You log in at /keystatic with your GitHub account and edit pages in a friendly admin UI. Each save commits to git and the site redeploys automatically.
What if I need a custom feature later? +
The stack is extensible. If you need a booking widget, a member portal, or a CRM sync, I scope it as a separate project with its own fixed price.
What's the catch? +
None. The only ongoing cost is hosting (typically $0 to $20 per month depending on traffic) and a domain name.
