Questions

Things people ask

Do I own the code and content?
Yes. Everything sits in a git repo in your GitHub account. Hosting is in your name. If we ever part ways, the whole site comes with you.
How do edits work?
You log in at /keystatic with your GitHub account and edit pages in a friendly admin UI. Each save commits to git and the site redeploys automatically.
What if I need a custom feature later?
The stack is extensible. Need a booking widget, a member portal, a CRM sync? We scope it as a separate project.
What's the catch?
None. The only ongoing cost is hosting (typically $0-20/month depending on traffic) and a domain name.
